# Reading Statistics Sync

Sync measured reading activity from official CrossPoint to Techy-Notes, with or without an existing account. Scan the QR to prefill the XXXX-XXXX reader code and confirm; guests can later link an existing KOSync account. Open the paired plugin for a fresh one-time web sign-in code. Subsequent sessions use a revocable token saved on the SD card; no extra username or password is required on the reader.

This beta targets sync-beta.techy-notes.com. Compatible CrossPoint firmware must emit `reader.session` events. For offline page-turn and calendar statistics on Razor-Crest, install the separate Reading Statistics plugin instead.
